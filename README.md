# hypixelpath

Файлы мини-приложения коопа Cucumber (Hypixel SkyBlock). Скрипт Google-таблицы коопа берёт их отсюда
и кэширует на 10 минут, поэтому изменения здесь появляются в приложении без перевставки кода скрипта.

- `app.html` — страница мини-приложения (путь, кооп, пройдено, справочник квестов, вопросы ИИ-советнику). Собирается из `src/`, руками не править.
  `__LIVE__` и `__ROAD__` заполняются при открытии.
- `widget.html` — HTML-виджет для Telegram (не больше 4 КБ после zlib и 32 КБ без сжатия).
- `roadmap.json` — путь прокачки: главы, шаги, роли и проверки по Hypixel API.

Ключей и токенов здесь нет и быть не должно: они хранятся только в настройках скрипта.
Чтобы применить изменения сразу: «Квесты коопа → Обновить приложение из GitHub».

## GitHub Pages

`index.html` — вход в мини-приложение: `https://wwlevramww.github.io/hypixelpath/?p=<ник>&api=<адрес /exec скрипта>`,
`&obs=1` — оверлей для OBS. Страница берёт `app.html` и `roadmap.json` отсюда, а прогресс коопа — у скрипта таблицы
(`?api=live`, отметки — `?api=mark`, вопросы ИИ — `?api=asks` и POST `{api: "ask"}`). Ссылки с нужными параметрами присылает бот по команде `/app`.

## Исходники

- `src/app.html` — шаблон страницы: стиль «деревянный пиксельный HUD», весь пиксель-арт (рамки, иконки, острова)
  нарисован в коде картами пикселей, анимации пошаговые (`steps()`), при «уменьшить движение» выключаются.
- `src/guide-data.json` — справочник: квесты журнала, Главы островов, Rift, фракции Crimson Isle.
- `tools/build.py` — собирает `app.html`: `python3 tools/build.py`.
